# Materiale di addestramento — Motore Contenuti Rivolio

Questi file **non ridefiniscono i tuoi agenti** (Rivo Stratega, Rivo Video, Rivo Caroselli
esistono già con i loro ruoli). Sono **pacchetti di conoscenza per argomento**: sapere,
tecniche e regole estratte dai video studiati + verificate online (ago 2026), da **allegare
agli agenti come materiale** per renderli più forti.

Ogni file è autonomo. Puoi darne uno, alcuni o tutti all'agente giusto.

## Indice del materiale

| File | Argomento | Utile soprattutto a |

| `00-fondamenta.md` | Brand, prodotto (EU261), funnel, KPI, regole legali AI | Tutti |

## Le 3 regole che attraversano tutto il materiale

1. **KPI unico = pratiche avviate**, non le views.
2. **Progetta per l'inoltro (il "send"):** è il segnale #1 del 2026 (pesa 3-5x un like).
3. **Giulia dichiarata AI** (obbligo di legge); la proof resta umana e vera.
